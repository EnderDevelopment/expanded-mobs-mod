# Expanded Mobs Mod

A Fabric mod that expands the Minecraft world with new mobs, biomes, structures, and a new dimension.

## Features

- Adds new mobs like Flowper, Shloter, Jumping Spider, Fly, and Falcon
- Includes new biomes and structures
- Expands the Minecraft world with a new dimension

## Requirements

- Minecraft 1.20.4
- Fabric Loader 0.14.0 or higher

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/expanded-mobs-mod/releases)
2. Place the mod file in your `mods` folder
3. Launch Minecraft with Fabric Loader

## Usage

Once installed, the new mobs, biomes, structures, and dimension will be available in your Minecraft world.

## Configuration

The mod does not currently support configuration files. Future updates may include this feature.
